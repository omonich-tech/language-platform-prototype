# Тестовый прототип платформы для учителей языков

Кликабельный прототип: три роли (клиент, учитель, администратор), запись на пробный урок, пакеты, тестовая оплата, комната урока с пометками, выплаты, споры и вкладка аналитики интерфейса.

Оплата и сообщения ненастоящие. Это не боевая версия.

## Как открыть

Откройте `index.html` в браузере или страницу GitHub Pages этого репозитория.

## Где хранятся данные

- На GitHub Pages и при локальном открытии данные лежат только в браузере (localStorage).
- В Claude-версии прототипа данные общие: их хранит база артефакта, поэтому клиент, учитель и администратор могут работать с разных устройств.

Для общей базы вне Claude нужен отдельный сервер, например Supabase.

## Что решено, а что нет

Комиссия 12%, оплата учителю за пробный урок $0 и курс 12 000 сум за $1 — условные числа для теста, не решения. Ссылки на видеозвонок тестовые.

## Видеоурок внутри сайта

В комнате урока кнопка «Начать видеоурок» запускает звонок прямо на странице, без Zoom, Meet и чужих аккаунтов. Видео идёт напрямую между браузерами учителя и ученика (WebRTC, библиотека PeerJS внутри файла). Показ экрана и отключение микрофона и камеры есть.

Как это работает: у каждого урока есть код комнаты. Оба человека открывают урок и нажимают ту же кнопку. Если данные не общие (GitHub Pages, разные устройства), второй вводит код вручную.

Ограничения тестовой версии: встречу помогает устроить бесплатный публичный сервер PeerJS (0.peerjs.com), без гарантий. Примерно в 1 из 10 сетей прямое соединение не устанавливается, и для этого нужен свой TURN-сервер. Для рабочей версии нужен собственный сервер соединений. Для групповых уроков этот способ не подходит.

## Общая доска

В комнате урока под видеозвонком есть доска: карандаш, ластик, текст, 4 цвета, «Отменить» и «Очистить». Пока идёт видеоурок, то, что рисует один, сразу видит второй: рисунок идёт по тому же прямому соединению, что и видео. Доска каждого ученика сохраняется в браузере на этом устройстве. Доска не общая в базе: если открыть урок на другом устройстве без видеозвонка, рисунок оттуда не подтянется. Для постоянной общей доски нужен сервер.
